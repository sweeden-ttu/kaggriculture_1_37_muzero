# K-Step Unroll with Explicit Stop-Gradient for 

In standard **MuZero**, the internal world model is trained exclusively on scalar task targets: policy, value, and reward predictions. Because there is no explicit supervision enforcing how abstract latent states should be structured, the latent trajectories generated by unrolling the dynamics network (\\(g_\theta\\)) naturally **depart and drift away** from the latent embeddings produced by directly encoding environment observations (\\(h_\theta\\)).

Self-supervised consistency losses (pioneered in **EfficientZero** and explored in **MuZero Latent Regularization**) stabilize the representation function and dynamics model through four primary mechanisms:

---

### 1. Eliminating Latent Representation Drift & Distributional Shift
Without explicit consistency constraints, the latent space is completely unconstrained, causing \\(g_\theta\\) to produce latent states that occupy an entirely different region of the representation space than \\(h_\theta(o_{t+k})\\). This **distributional shift** between \\(h_\theta\\) root states and \\(g_\theta\\) unrolls causes predicted latent representations to degenerate over multi-step rollouts.

By adding a self-supervised consistency loss, the model explicitly penalizes the distance (typically using **negative cosine similarity** or **MSE**) between the predicted unrolled latent state \\(\hat{s}_{t+k}\\) and the true observation embedding \\(h_\theta(o_{t+k})\\). Visualizations confirm that this forces latent forward dynamics trajectories to remain congruent with ground-truth observation embeddings.

---

### 2. Providing Dense Representation Supervision (Sparse Reward Solvency)
Because vanilla MuZero relies entirely on scalar reward and value predictions, the representation network \\(h_\theta\\) struggles to receive informative gradients in **sparse-reward environments** or **low-data regimes**. 

Observation embeddings \\(h_\theta(o_{t+k})\\) provide rich, high-dimensional temporal signals. Enforcing consistency across adjacent time steps acts as a dense auxiliary task, forcing \\(h_\theta\\) and \\(g_\theta\\) to retain critical environmental features (such as entity positions and tile states) even before task rewards are encountered.

---

### 3. Asymmetric Optimization via Stop-Gradients
To prevent trivial representation collapse (where the encoder shrinks its representations to zero or a constant to easily match a bad dynamics model), consistency losses utilize an **asymmetric SimSiam / BYOL architecture**:
* **Target Branch**: The real future observation \\(o_{t+k}\\) is passed through the encoder \\(h_\theta\\) and a projector network, accompanied by a **stop-gradient (`stop-grad`) operator**.
* **Predictor Branch**: The unrolled latent state from \\(g_\theta\\) passes through a projector and an additional predictor MLP head.

By blocking error gradients through the target encoder \\(h_\theta\\), the loss forces the **dynamics network \\(g_\theta\\) to move towards the observation embeddings** rather than pulling the encoder towards an unconstrained dynamics space.

---

### 4. Enhancing Long-Horizon MCTS Search Stability
When MCTS plans deep into the search tree, compounding prediction errors in unconstrained latent spaces cause leaf values to hallucinate or degrade. Stabilizing the latent space via consistency loss allows agents to maintain accurate predictions across far longer planning horizons—enabling "blindfolded" agents to plan effectively up to 200 steps into the future without seeing raw observations.

### PyTorch Implementation: `simsiam_consistency.py`

```python
import torch
import torch.nn as nn
import torch.nn.functional as F
from typing import Dict, List, Tuple

class SimSiamProjectionPredictionHead(nn.Module):
    """
    Asymmetric Projection and Prediction heads for SimSiam-style latent consistency.
    
    Structure:
    1. Projection Head (g_proj): Latent State -> Projected Embedding
    2. Prediction Head (p_pred): Projected Embedding -> Predicted Target Vector
    """
    def __init__(self, latent_dim: int = 256, proj_dim: int = 256, pred_dim: int = 64):
        super().__init__()
        
        # Projection Head: Maps latent states s to projection space
        self.proj_head = nn.Sequential(
            nn.Linear(latent_dim, proj_dim, bias=False),
            nn.BatchNorm1d(proj_dim),
            nn.ReLU(inplace=True),
            nn.Linear(proj_dim, proj_dim, bias=False),
            nn.BatchNorm1d(proj_dim),
            nn.ReLU(inplace=True),
            nn.Linear(proj_dim, proj_dim, bias=False),
            nn.BatchNorm1d(proj_dim)
        )
        
        # Prediction Head: Bottleneck MLP that introduces asymmetry (prevents collapse)
        self.pred_head = nn.Sequential(
            nn.Linear(proj_dim, pred_dim, bias=False),
            nn.BatchNorm1d(pred_dim),
            nn.ReLU(inplace=True),
            nn.Linear(pred_dim, proj_dim)
        )

    def project(self, latent_state: torch.Tensor) -> torch.Tensor:
        """Computes projection vector g_proj(s)."""
        return self.proj_head(latent_state)

    def predict(self, projected_state: torch.Tensor) -> torch.Tensor:
        """Computes prediction vector p_pred(g_proj(s))."""
        return self.pred_head(projected_state)

class SimSiamConsistencyLoss(nn.Module):
    """
    Computes Negative Cosine Similarity with explicit Stop-Gradient on the target branch.
    
    Loss = - CosineSimilarity( p_pred(g_proj(s_unrolled)), detach(g_proj(h_encoder(o_target))) )
    """
    def __init__(self, eps: float = 1e-8):
        super().__init__()
        self.eps = eps

    def forward(
        self, 
        unrolled_latent: torch.Tensor, 
        target_observation_embedding: torch.Tensor,
        simsiam_head: SimSiamProjectionPredictionHead
    ) -> torch.Tensor:
        """
        Args:
            unrolled_latent: Predicted latent state s_hat_{t+k} from dynamics g_theta [Batch, Latent_Dim]
            target_observation_embedding: Real latent state z_{t+k} from encoder h_theta(o_{t+k}) [Batch, Latent_Dim]
            simsiam_head: Module containing projection and prediction networks
            
        Returns:
            Scalar SimSiam consistency loss
        """
        # 1. Predictor Branch (Gradients flow back through dynamics network g_theta)
        p_k = simsiam_head.predict(simsiam_head.project(unrolled_latent))
        
        # 2. Target Branch (Explicit STOP-GRADIENT on the observation encoder target)
        with torch.no_grad():
            z_k_target = simsiam_head.project(target_observation_embedding).detach()

        # 3. L2 Normalize both prediction and target vectors
        p_k_norm = F.normalize(p_k, dim=-1, eps=self.eps)
        z_k_norm = F.normalize(z_k_target, dim=-1, eps=self.eps)

        # 4. Negative Cosine Similarity Loss: - sum(p * z) across feature dimensions
        # Range: [-1.0, 1.0] where -1.0 represents perfect directional alignment
        cosine_sim = (p_k_norm * z_k_norm).sum(dim=-1)
        loss = -cosine_sim.mean()
        
        return loss

def compute_muzero_unroll_loss_with_consistency(
    model_representation: nn.Module,   # h_theta
    model_dynamics: nn.Module,         # g_theta
    model_prediction: nn.Module,       # f_theta
    simsiam_head: SimSiamProjectionPredictionHead,
    simsiam_loss_fn: SimSiamConsistencyLoss,
    observations: torch.Tensor,        # Stacked observations [Batch, K+1, Channels, H, W]
    actions: torch.Tensor,             # Unroll actions [Batch, K, Action_Dim]
    target_policies: torch.Tensor,     # MCTS target policy distributions [Batch, K+1, Action_Dim]
    target_values: torch.Tensor,       # MCTS target value scalars [Batch, K+1]
    target_rewards: torch.Tensor,      # Realized environment rewards [Batch, K]
    consistency_weight: float = 0.25,  # Weight scaling factor lambda
    unroll_steps: int = 5
) -> Tuple[torch.Tensor, Dict[str, float]]:
    """
    Executes a K-step MuZero unroll loop incorporating policy, value, reward,
    and SimSiam self-supervised consistency losses.
    """
    total_policy_loss = 0.0
    total_value_loss = 0.0
    total_reward_loss = 0.0
    total_consistency_loss = 0.0

    # ------------------------------------------------------------------
    # Step 0: Root Observation Encoding (t = 0)
    # ------------------------------------------------------------------
    # Initial observation o_0 -> root latent state s_0
    s_current = model_representation(observations[:, 0])
    
    # Root Prediction: Policy & Value
    pred_0 = model_prediction(s_current)
    total_policy_loss += F.cross_entropy(pred_0['policy_logits'], target_policies[:, 0])
    total_value_loss += F.mse_loss(pred_0['value'], target_values[:, 0])

    # ------------------------------------------------------------------
    # K-Step Recurrent Unroll Loop (k = 1 ... K)
    # ------------------------------------------------------------------
    for k in range(1, unroll_steps + 1):
        a_k = actions[:, k - 1]
        
        # 1. Unroll Dynamics: s_hat_k, r_hat_k = g_theta(s_hat_{k-1}, a_k)
        s_unrolled, r_predicted = model_dynamics(s_current, a_k)
        
        # 2. Compute Standard Task Predictions: f_theta(s_hat_k)
        pred_k = model_prediction(s_unrolled)
        total_policy_loss += F.cross_entropy(pred_k['policy_logits'], target_policies[:, k])
        total_value_loss += F.mse_loss(pred_k['value'], target_values[:, k])
        total_reward_loss += F.mse_loss(r_predicted, target_rewards[:, k - 1])

        # 3. Compute Ground-Truth Target Embedding: z_k = h_theta(o_k)
        # We encode real observation o_k from the buffer
        target_z_k = model_representation(observations[:, k])

        # 4. Compute SimSiam Consistency Loss between s_unrolled and target_z_k
        c_loss_k = simsiam_loss_fn(s_unrolled, target_z_k, simsiam_head)
        total_consistency_loss += c_loss_k

        # Carry forward unrolled state for next recurrent step
        s_current = s_unrolled

    # Normalize losses across time steps
    mean_policy_loss = total_policy_loss / (unroll_steps + 1)
    mean_value_loss = total_value_loss / (unroll_steps + 1)
    mean_reward_loss = total_reward_loss / unroll_steps
    mean_consistency_loss = total_consistency_loss / unroll_steps

    # Total Joint Loss
    total_loss = (
        mean_policy_loss + 
        0.25 * mean_value_loss + 
        mean_reward_loss + 
        consistency_weight * mean_consistency_loss
    )

    metrics = {
        'loss_total': total_loss.item(),
        'loss_policy': mean_policy_loss.item(),
        'loss_value': mean_value_loss.item(),
        'loss_reward': mean_reward_loss.item(),
        'loss_consistency': mean_consistency_loss.item(),
    }

    return total_loss, metrics
```

### Key Architectural Highlights

1. **Explicit Stop-Gradient**: The target branch wraps `simsiam_head.project(target_observation_embedding)` inside `with torch.no_grad():` and calls `.detach()`. This blocks gradients from pulling the observation encoder toward unconstrained dynamics.
2. **Asymmetric Predictor Head**: The `pred_head` bottleneck MLP acts as an asymmetric operator on the unrolled branch, breaking symmetry and preventing the collapse to constant vector outputs.
3. **L2 Normalization**: The normalized negative cosine similarity bounds individual step consistency losses in the range \\([-1.0, 1.0]\\), keeping gradient scales balanced with policy and value cross-entropy losses.
